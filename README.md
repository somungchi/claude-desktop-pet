# claude-desktop-pet

화면 구석에 사는 작은 데스크톱 펫입니다. 실수하면 뒤돌아서 사과하고, 쓰다듬으면 친밀도가 오르고, 친밀도가 오르면 엉뚱한 선물(황금 목걸이, 지렁이, 꿀사과…)이나 옷을 주워옵니다.

> **비공식 팬 프로젝트입니다.** Anthropic 및 Claude와 관련이 없으며 공식 로고·이미지를 쓰지 않았습니다. 캐릭터는 도형으로 직접 그린 것입니다.

## 실행

Windows, Python 3.9+ (tkinter 포함). 선물 이미지를 보려면 Pillow가 필요합니다(없으면 상자 아이콘으로 대체).

```
pip install pillow             # 선물/소품 사진 표시
pip install "rembg[cpu]"       # (선택) AI 누끼. 없으면 흰 배경만 지우는 간이 방식. 첫 실행 때 모델(약 170MB)을 내려받음
pythonw claude_pet.py      # 콘솔 없이 실행 (에러를 보려면 python claude_pet.py)
```

## 조작

| 동작 | 방법 |
|---|---|
| 쓰다듬기 | 머리 위에서 마우스를 좌우로 왔다갔다 (친밀도 +1, 최대 100) |
| 엉덩이 때찌 | 뒤돌아 사과 중일 때 엉덩이 클릭 |
| 옮기기 | 머리를 잡고 끌었다 놓기 (발버둥 치고, 놓으면 쿵 하고 착지) |
| 대화 | 우클릭 → 머리 위 말풍선이 입력칸으로 바뀜(커서 깜빡임), Enter 전송 / Esc 취소 |

대화 명령: `가만있어` `앉아` `엎드려 뻗쳐` `일어나` `돌아다녀` `통통` `휘파람` `쉬어`(주머니에서 의자를 꺼내 앉음) `사다리`(사다리 타고 올라감) `배추`(배추 심어서 수확)
질문: `몇 시야?` `오늘 며칠?` `12*3+4는?` `이름이 뭐야` `친밀도` `옷` `선물` `도움말`

## 외부에서 호출 (로컬 전용, 127.0.0.1:47321)

```
curl http://127.0.0.1:47321/sorry   # 사과하며 뒤돌기
curl http://127.0.0.1:47321/hi      # 인사
curl http://127.0.0.1:47321/quit    # 종료
```

예: 스크립트나 훅에서 실패했을 때 `/sorry`를 호출하면 펫이 사과합니다.

## 선물 이미지

선물 이미지는 실행 중에 [Wikimedia Commons](https://commons.wikimedia.org) 검색으로 가져옵니다(저장소에 포함하지 않음). 이미지마다 라이선스가 다릅니다. 검색어 외에 개인정보는 전송하지 않습니다.
